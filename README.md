# Notes App

## Overview

The Notes App is a simple text-based notes manager implemented in Java. It allows users to add and view notes, which are stored in a text file. This project demonstrates basic file I/O operations in Java using FileWriter for writing notes and BufferedReader for reading notes.

## Features

- Add notes to a text file.
- View all saved notes.
- Simple command-line interface.

## Technologies Used

- Java
- VS Code (or any Java IDE)
- Terminal

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed on your machine.
- A text editor or IDE (e.g., VS Code, IntelliJ IDEA).
- Basic knowledge of Java and command-line operations.

### Installation
1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/yourusername/notes-app.git

2. Navigate to the project directory:

cd notes-app

3. Compile the Java file:

javac NotesApp.java

4. Run the application:

java NotesApp

Usage

1. When the application starts, you will see a menu with the following options:

• 1. Add Note: Enter your note to save it.

• 2. View Notes: Display all saved notes.

• 3. Exit: Close the application.

2. Follow the prompts to interact with the application.
